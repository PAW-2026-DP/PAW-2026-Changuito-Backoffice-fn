Frontend de gestión de la aplicacion web Changuito, orientado a los supermercados adheridos y a los administradores de la plataforma.

Esta primera version contiene solamente la estructura inicial del repositorio. No incluye archivos HTML, CSS ni JavaScript.

## Objetivo del backoffice

El backoffice sera la interfaz web para los roles de gestión de Changuito. Permitira:

### Panel de supermercado

- Alta, baja y modificación de productos del catálogo.
- Actualización de precios y stock por sucursal.
- Bandeja de pedidos entrantes, con cambio de estado de preparación (confirmado, en preparación, listo para retiro).

### Panel de administrador

- Gestión de usuarios y roles.
- Alta de comercios y sucursales.
- Definición de zonas de cobertura y costos de envío.

## Stack previsto

- HTML5
- CSS3
- JavaScript sin frameworks
- Comunicacion con el backend mediante solicitudes HTTP

## Estado actual

Repositorio inicial. No hay archivos HTML, CSS, JavaScript ni dependencias configuradas todavía.
